# Ahonakpon Guy Gbaguidi — Personal Website

A static, multi-page personal website for software engineering, AI research, projects, and community work.

## Run locally

This site has no build step. From the project root, run:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Pages

- `index.html` — home, selected work, news, and call to action
- `about.html` — biography, education, and skills
- `projects.html` — case studies and technologies
- `experience.html` — professional experience and leadership
- `research.html` — research interests and publication
- `organizations.html` — institutions and communities
- `contact.html` — direct contact, social links, CV download, and email form

The contact form is static-site friendly: it opens the visitor’s mail application with a pre-filled email.
